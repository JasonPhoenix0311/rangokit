# Seguridad

Rangokit es una página estática: no tiene servidor ni pide cuentas. Los proyectos y lo que aprende Rango se guardan solo en el navegador de quien lo usa. La única conexión externa es la búsqueda opcional en la API pública de GitHub, que envía solo las palabras de búsqueda visibles. Sus resultados se tratan como contenido no confiable: se escapan y se muestran como enlaces.

Si encuentras un problema de seguridad, como código que se pueda inyectar por medio de un enlace o un archivo, no abras un issue público. Repórtalo en privado desde la pestaña **Security** del repositorio, con la opción **Report a vulnerability**.

Incluye los pasos para reproducirlo y qué podría hacer alguien con él. Responderemos en cuanto podamos.
